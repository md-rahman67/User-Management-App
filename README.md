# User Management App

A simple CRUD application built using Node.js, Express.js, MySQL, and EJS.

### Features
- Add, view, edit, and delete users
- Store user data in MySQL
- Dynamic pages using EJS

### Tech Stack
Node.js • Express.js • MySQL • EJS • JavaScript

### Run Locally
```bash
npm install
node index.js
```

Open `http://localhost:8080` in your browser.

**Note:** Configure your `.env` file with your MySQL credentials before running the app.
